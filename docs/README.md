browser integration, and deployment guidance so each can be reviewed on its
own terms.

The accompanying [paper](../paper/paper.pdf) gives the scientific rationale,
equations, references, limitations, and reproducibility requirements. The
[OpenAPI document](http://127.0.0.1:8765/openapi.json) is generated by a running
service and is the machine-readable HTTP schema.

## Contract hierarchy

When documents appear to conflict, use this order:

1. published API schema and versioned artifact manifest;
2. model and validation contracts;
3. deployment and integration guidance;
4. tutorial and demo text.

Please report a discrepancy as a documentation bug. Scientific defaults must
never drift silently between code, manifests, examples, and documentation.
