# Scientific paper

`paper.tex` is the authoritative English methods paper; `references.bib`
contains primary standards and scientific literature. Build it with:

```bash
python3 /path/to/compile_latex.py paper.tex --output-directory build
```

The committed `paper.pdf` is generated from these sources. Please cite the
software using the repository-level `CITATION.cff`.

Substantial scientific contributions may qualify for co-authorship in a future
revision. See the repository's `CONTRIBUTING.md` for the criteria, manuscript
approval requirement, and attribution process.
